# 用户中心前端（pkuse-token-demo-user-center-server-vue3）

Pkuse-Token 用户中心的 Vue3 前端：**统一登录页 / 工作台 / 用户管理 / 应用管理 / 登录日志 / 操作日志 / 规则配置 / 修改密码**。

- 技术栈：Vue 3.4 + Vite 4 + Vue Router 4 + Axios + Element Plus 2.8
- 端口：`8090`（`/api`、`/sso` 已代理到后端 `http://localhost:8091`）
- 后端工程：`../pkuse-token-demo-user-center-server`
- 完整启动步骤与演示说明：见 `../README.md`

## 页面

| 路由 | 页面 | 可见角色 | 说明 |
| --- | --- | --- | --- |
| `/login` | 统一登录页 | 公开 | 账号密码登录；携带 `?redirect=` 时登录后整页跳回认证中心授权地址 |
| `/workbench` | 工作台 | 全部登录用户 | 管理员：统计、已接入应用、认证中心信息；普通用户：只有「我的应用」（已授权应用入口） |
| `/user` | 用户管理 | 仅系统管理员 | 查询 / 新增 / 编辑 / 启用禁用 / **授权应用**（含批量授权）/ 重置密码 / 删除 / **在线解锁** / **设备管理（解绑）** |
| `/client` | 应用管理 | 仅系统管理员 | 应用查询 / 新增 / 编辑（回调地址、应用入口、密钥）/ 启用禁用 / 删除 |
| `/log` | 登录日志 | 仅系统管理员 | 登录/注销记录查询（账号、结果、时间范围；按月分表 `uc_login_log_yyyyMM`） |
| `/operlog` | 操作日志 | 仅系统管理员 | 管理动作审计（操作人、模块、动作、结果、时间范围筛选；「详情」查看传参与**修改前/修改后数据**（脱敏），按月分表 `uc_oper_log_yyyyMM`） |
| `/config` | 规则配置 | 仅系统管理员 | 密码规则 / 登录规则 / 日志规则（16 项）在线维护：开关、数值、下拉选项，保存即时生效，可一键恢复默认 |
| `/password` | 修改密码 | 全部登录用户 | 原密码 + 新密码（SM2 加密传输），页面提示当前密码规则；开启「首次登录强制修改密码」后由登录页带 `?force=1` 自动进入，改密完成继续原跳转（如 SSO 回跳地址） |

> 菜单与路由均按角色控制：普通用户看不到「用户管理 / 应用管理 / 登录日志 / 操作日志 / 规则配置」，直接访问会被守卫拦回工作台
> （后端同样返回 `code=403`）；「修改密码」对所有登录用户开放，入口在右上角用户下拉菜单中。
> 后端返回 `code=426`（需先修改初始密码）时，请求拦截器会统一引导跳转 `/password?force=1`。

## 登录态与权限

- `token` 存入 `localStorage`，XHR 请求通过 `satoken` 请求头携带（`src/utils/request.js` 统一注入与 401 处理）；
- 同时把 `token` 同步写入 Cookie：浏览器整页跳转到认证中心 `/sso/auth` 时自动携带登录态；
- 角色判断见 `src/utils/auth.js#isAdmin`（`role === 'admin'`），用于菜单显示与路由守卫；
- 开发环境前端 8090 与后端 8091 同为 `localhost`（Cookie 不区分端口），生产环境建议同域部署。

```bash
npm run dev       # 开发模式  http://localhost:8090
npm run build     # 构建产物输出到 dist/

```
